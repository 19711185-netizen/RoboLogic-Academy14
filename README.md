# RoboLogic Academy

## Bienvenidos a RoboLogic Academy

RoboLogic Academy es una plataforma web interactiva para aprender programación y lógica robótica.

### Nuestro objetivo
Enseñar programación de una manera fácil, creativa y divertida.

### ¿Qué encontrarás?
- Cursos de programación.
- Juegos educativos.
- Retos de lógica.
- Actividades de robótica.

### Idioma
Español.
